Condition that evaluates to true when Performer is the same entity as Holder (i.e., the effect was self-applied). Returns false when Performer is null.

Remarks

This is a strict reference-identity check and does not walk Owner. Under composition (e.g. a weapon entity applying an effect on behalf of its owning ship) a self-applied effect where Performer is the weapon and Holder is the ship evaluates to false here even though the ship is, in a broader sense, affecting itself. Use IsOwnedByCondition (e.g. Owned = Holder, Owner = PerformerOwner) for ownership-aware "is this self-inflicted" checks.
