Properties

Class

Gets or sets the class definition for this entity. Setting a different value raises OnClassChanged and then the per-entity class-changed game event channel; reassigning the same class is a no-op and raises nothing. Safe to call before Awake (e.g. during spawn setup on a deactivated GameObject).
